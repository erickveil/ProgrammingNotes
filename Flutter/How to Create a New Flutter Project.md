
# VS Code

https://docs.flutter.dev/tools/vs-code

The trick is to activate the inexplicably hidden **Command Palette**:

```
Ctrl + Shift + P
```

Then it will transform the useless search bar at the top into that list of commands that you're used to seeing there. Click on it and you should see `Flutter: New Project` right there in the drop down. Or you can type it.

That's it.

## Initialize the Repository

Before you do *anything*, switch over to the git tab and initialize your repository.

Half the other buttons are going to start modifying stuff, so it's best to get your starting space saved and comitted.

## The First Build

In the lower right hand corner, in the status bar, make sure it says "Windows (windows-x64)" - This is the target device for building. It might default to that android phone you have plugged in or Edge Browser, so make sure you're running on where you want it before hitting that "Run and Debug" button on the left pannel.
